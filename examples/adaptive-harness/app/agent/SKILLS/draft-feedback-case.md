# Draft feedback case — prompt skill

This is a **prompt-only** drafting skill. It does not file cases or bypass the feedback gate.

From the available conversation, draft a concise candidate with: observed behavior, expected behavior, evidence/steps to reproduce, provisional taxonomy (verification, agent-behavior, reliability, or other), possible recurrence, and a deterministic replay check.

Mark unverified claims and unknown recurrence clearly. Never invent an issue number, receipt, URL, or a claim of filing. The chat's GitHub Case filing is pending-only; any real submission needs the authorized intake path and independent readback.
